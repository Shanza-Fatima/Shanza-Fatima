## Featured project

### 🔒 [Privacy Blur with YOLO](https://github.com/Shanza-Fatima/Privacy-blur-with-YOLO)

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?logo=opencv&logoColor=white) ![YOLO11](https://img.shields.io/badge/Ultralytics-YOLO11-00A3AD) ![ONNX](https://img.shields.io/badge/ONNX%20Runtime-005CED?logo=onnx&logoColor=white)

A real-time privacy blur for video. A pretrained YOLO11n model finds people, phones and laptops, and each region is blurred with a strength that scales with the object size. I benchmarked it on a laptop CPU against an ONNX export and a classic Haar baseline.

| Detector | FPS on CPU |
| --- | --- |
| YOLO11n, input 640 | 15.0 |
| YOLO11n, input 320 | 34.4 |
| YOLO11n, ONNX Runtime, input 320 | 39.5 |
| Haar face detector (baseline) | 3.3 |

Measured on an Intel Core i7-8665U with 242 frames. Speed only, accuracy was not evaluated. Full method, results and limitations are in the [repository](https://github.com/Shanza-Fatima/Privacy-blur-with-YOLO).
